# Tether discovery-only pilot gate

This entry wraps the unchanged native Worker. It opens only exact `/mcp`, default closed, with explicit `TETHER_DISCOVERY_GATE=open-tether-discovery-only` and decimal millisecond `TETHER_DISCOVERY_STARTS_AT` / `TETHER_DISCOVERY_EXPIRES_AT`. The absolute interval must be positive and at most 300000 ms. Both request admission and reply release check the interval. No registration/probe route or WebSocket is opened. Existing native auth/assertion/header/Origin/body/time limits remain unchanged.

This is a path gate, NOT an MCP body policy or authenticator. Discovery-only depends on a NEW dedicated gateway process constructed with empty routes, no Mac agent/grant and no registration during its lifetime. Never reuse a gateway that has a live route. Existing `agentgateway` discovery regressions prove nil-route initialize/catalog and tools/call 404 with zero dispatch. A route must not be inferred absent merely from successful initialize/tools/list. Preserve the new container identity, image/binary hash, fixed configuration hash and startup evidence; add no public inventory/status endpoint. CLI tools/call permissions remain disabled.

Deployment is a separate approval. Keep the existing fixed VPC target/loopback port and protected config. No new keys/auth/route. Start a fresh least-privileged finite-life container, independently supervise absolute gate closure and only its stop, and deploy closed on completion/failure. The existing watchdog contract is required, not replaced by Worker clock checks. In-flight requests are not retroactively canceled by this path gate; native per-request timers and backend lifetime still apply. Clock rollback can affect wall-clock admission, so independently timed watchdog/container lifetime are mandatory. No automatic renewal/restart.

Run synthetic regressions with `node --test deploy/cloudflare/discovery/worker.test.mjs deploy/cloudflare/native/worker.test.mjs deploy/cloudflare/probe/worker.test.mjs`. No real assertion, network, account, OAuth, container or Mac execution is exercised. Linux binary compilation is not deployment.
